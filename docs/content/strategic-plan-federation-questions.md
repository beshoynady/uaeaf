# الخطة الاستراتيجية — ما نحتاجه من الاتحاد

**الغرض:** الصفحة مبنية ومنشورة محليًا بمحتوى إطار Figma. ما يلي هو ما لا تستطيع الهندسة ولا التصميم البتّ فيه: أرقام الاتحاد وحقائقه ووثائقه وصوره. كل بند يذكر أين يظهر في الصفحة، ومن يعدّله، وما الذي يتغيّر في الكود إن لزم.

**آخر تحديث:** 2026-09-16 · **المرجع:** `docs/design-system/ADR-0075-…md`

## ١. ربط الأهداف بالمحاور

**أين:** قسم «من المحاور إلى أهداف ملموسة» (الأهداف الخمسة) بعد قسم «محاورنا الاستراتيجية» (المحاور الستة).

**المشكلة:** عنوان القسم يعد بالربط، والصفحة لا تُظهر أي هدف يخدم أي محور. الألوان في القائمتين تتبع الموضع لا المعنى، فيبدو الهدف ١ مرتبطًا بالمحور ١ وهو ليس كذلك.

**المطلوب من الاتحاد:** لكل هدف من الخمسة، اسم المحور الذي يخدمه (محور واحد أو أكثر).

| الهدف | المحور/المحاور |
| --- | --- |
| رفع مستوى الأداء الرياضي | |
| توسيع قاعدة المواهب | |
| تعزيز المشاركة | |
| تطوير منظومة المنافسات | |
| تعزيز الحوكمة | |

**أثر ذلك على الكود:** إظهار الربط في الصفحة يحتاج حقلًا جديدًا في الـschema (`parentPillarId` لكل هدف) وتعديلًا في شاشة الداشبورد. قرار المالك 2026-09-16: يُؤجَّل حتى يصل المحتوى.

## ٢. المؤشرات: خط الأساس وسنة الهدف

**أين:** قسم «نقيس التقدم، ونصنع الأثر» — أربعة أرقام.

**المشكلة:** «2030» أفق زمني يُعرض كمؤشر ويُعدّ تصاعديًا من الصفر. و«+30%» و«+25%» بلا سنة أساس ولا سنة هدف، فلا يمكن للقارئ معرفة مقارنة بماذا.

**المطلوب:**

| الرقم كما يظهر | التسمية | القيمة الحالية | سنة الأساس | القيمة المستهدفة | سنة التحقق |
| --- | --- | --- | --- | --- | --- |
| 2030 | أفق الخطة الاستراتيجية | | | | |
| 15 | برنامجًا للتطوير والتأهيل | | | | |
| +30% | زيادة المشاركة في المنافسات | | | | |
| +25% | نمو قاعدة المواهب | | | | |

**اليوم:** يمكن تعديل الرقم ونصّه من الداشبورد فورًا. خانات منفصلة لخط الأساس وسنة الهدف تحتاج حقولًا جديدة.

## ٣. فترة الخطة

**أين:** لا تظهر في أي مكان. «2030» تظهر أول مرة في منتصف الصفحة.

**المطلوب:** سنة بداية الخطة وسنة نهايتها (مثلًا 2024–2030).

**اليوم:** تُكتب في العنوان الفرعي للـhero من الداشبورد بلا أي تعديل برمجي.

## ٤. المراحل: التواريخ والمرحلة الحالية

**أين:** الشريط الأخضر الأول، أربع مراحل (الأساس · التطوير · التنافسية · الأثر).

**المطلوب:** السنوات التي تغطيها كل مرحلة، وأي مرحلة يقف فيها الاتحاد الآن.

**اليوم:** السنوات تُكتب داخل وصف كل مرحلة من الداشبورد. علامة «نحن هنا» تحتاج حقلًا جديدًا.

## ٥. خطوات التنفيذ: وصف لكل خطوة

**أين:** الشريط الأخضر الثاني، خمس خطوات (المحور الاستراتيجي · الهدف · المبادرة · القياس · الأثر) — كلمة واحدة لكل خطوة.

**المطلوب:** سطر لكل خطوة يشرح ما يحدث فيها داخل الاتحاد: من يملكها، وما مخرجها، وكل كم يُراجَع.

**اليوم:** حقل الوصف موجود في الشاشة وفارغ؛ يُملأ بلا تعديل برمجي.

## ٦. وثيقة الخطة للتنزيل

**أين:** لا يوجد. قسم الوثائق في إطار Figma حُذف بقرار المالك، فلم يعد في الصفحة مكان لتنزيل الخطة.

**المطلوب:** هل تُنشر وثيقة الخطة (PDF) للجمهور؟ وإن نعم: النسخة النهائية، وبأي لغة (أو اللغتين)، وهل تتغير مع كل تحديث.

**أثر ذلك:** إعادة القسم قرار مالك، ويحتاج حقل ملف في الـschema وخانة رفع في الشاشة.

## ٨. النص الإنجليزي

النص الإنجليزي كله ترجمة من العربية أعدّها فريق التنفيذ، لأن شاشات Figma الإنجليزية لم تُستعمل بقرار المالك. يحتاج مراجعة من الاتحاد قبل النشر العام.

## ٩. حدود يعرفها المحرر

- **المراحل وخطوات التنفيذ:** عشرة عناصر لكل قسم كحدّ أقصى؛ زر «إضافة» يتوقف عند العاشر ويشرح السبب.
- **بقية القوائم** (المحاور، الأهداف، المؤشرات): بلا حدّ.
- **لا يستطيع المحرر** تغيير ترتيب الأقسام الثمانية ولا إخفاء قسم كامل ولا ترك قسم بلا عنصر ظاهر.
