## إزاي تقرا الملفات
- النصوص عربي وإنجليزي جوه `renderVals()`، وكمان منطق الإظهار والإخفاء لكل حالة.
- قايمة «معاينة كـ» وأزرار التجربة أدوات عرض بس، ومش في المنتج.
- الأسماء والبيانات أمثلة للعرض. **مفيش بيانات مزروعة:** الأدمن بيدخّل كل حاجة من الداشبورد.
- النصوص اللي بين [ ] placeholders.
- `./support.js` في رأس كل ملف خاص ببيئة التصميم، ومالوش لازمة في المشروع.
