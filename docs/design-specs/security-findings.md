# ثغرات أمنية في كود قائم خارج نطاق هذه الجلسة

سُجِّلت وفق §10 بند 1. **لم تُصلَح** لأنها خارج النطاق المعتمد في §3.3.

## SEC-1 — ملف الرياضي الموقوف أو المعتزل مرئي للجمهور

**المكان:** `api/src/modules/people-organizations/athlete-profiles/athlete-profiles.repository.ts:21-23`
→ `BaseRepository.findOne`، يستدعيه `AthleteProfilesService.getPublicBySlug`
عبر المسار العام `GET /athlete-profiles/public/:slug`
(`athlete-profiles.controller.ts:34-38`).

**الوصف:** `AthleteProfile.status` يقبل `Active | Inactive | Suspended | Retired`
(`athlete-profile.schema.ts:11,55-56`)، والمسار العام **لا يرشّح عليه إطلاقًا** —
الفلتر الوحيد هو `{ slug, archivedAt: null }`. فملف رياضي موقوف أو معتزل أو غير نشط
يُعرض للجمهور اليوم بمجرد معرفة الـslug.

**قائم قبل هذه الجلسة.** مصدر البحث الجديد يطابق سلوك المسار العام تمامًا ولا يوسّع
الانكشاف، فإصلاحه هنا كان سيجعل البحث أضيق من الصفحة التي يشير إليها.

**الخطورة:** متوسطة. لا تسريب بيانات حساسة (الحقول المقيّدة — الهوية والعنوان والهاتف
والبريد — لا تُلمس)، لكن الإيقاف حالة انضباطية، وعرض ملف موقوف كأنه نشط مسألة حوكمة.

**الإصلاح المقترح:** إضافة فلتر الحالة إلى `getPublicBySlug`، وتحديد أي الحالات عامة —
قرار يخص الاتحاد لا المطوّر.
