## `html/` — نسخ تفاعلية
افتح أي ملف `.dc.html` في المتصفح مباشرة (مع `support.js` في نفس المجلد). `Main.dc.html` تفاعلية: فتح وإغلاق اللوحات، والوضع الداكن، والبحث عن موسم.

**القيم في الملفات (hex وpx) مرجع شكل فقط.** التنفيذ يستخدم توكنات الـdesign system، وممنوع نقل hex إلى الكود.
