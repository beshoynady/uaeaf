# مرجع Figma — لقطات وأصول

**الغرض:** نسخة دائمة داخل المستودع من إطارات Figma المقروءة، لأن الملف `hpO727vjwl18g3s3LTICAY` ("uaeaf-desgin") **للقراءة فقط ولا توجد نسخة أخرى منه**. أي لقطة تبقى في مجلد مؤقت تُفقد عند مسحه.

**Figma مرجع للمحتوى والبنية فقط.** لا يُؤخذ شكل أي عنصر من هذه الصور قبل مراجعة المالك البصرية. راجع `_review/`.

## التسمية

`<المجموعة>-<الاسم>-<node id بشرطة>.<png|svg>` — مثال: `core-load-more-2591-43.png` هو العقدة `2591:43`.

## عيب معروف في تصدير الأيقونات

كل ملف في `icons/` يحمل زيادتين من مصدِّر Figma:

- `<rect width="24" height="24" fill="#1E1E1E"/>` وهي خلفية الـ Section على canvas، وليست جزءًا من الرمز.
- إزاحة سالبة كبيرة في أول `path` (مثل `M-1117 -5174`) لأن الرمز مصدَّر بإحداثيات الصفحة.

هذه ملفات **مرجعية للأرشيف**، لا أصول إنتاج. القرار D6 يجعل الرسومات بانتظار المراجعة البصرية، والقرار س١٧ يحدد أيقونات Lucide المنسوخة مصدرًا لأيقونات الواجهة. أي استخدام إنتاجي يتطلب تنظيف الملف أولًا.
